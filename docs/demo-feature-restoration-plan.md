- 基準コミット: `cbe814b`

## 1. 目的

承認済みデモと `docs/ui-design-spec.md` で確定した操作モデルを、現在のR1実装へ復元する。見た目の一致ではなく、保存データ、計算、画面遷移、エラー、テストまで成立する縦断スライスとして実装する。

比較デモ内の不採用案は対象に含めない。具体的には、所持・育成管理の編集シート、独立所持登録カタログ、育成ボード、育成計画の育成対象別表示と対応表は復元しない。

## 2. 進め方

- このファイルを復元作業の進捗正本とする。
- 各スライスの開始時に状態を `未着手` → `実装中` へ変更する。
- 完了時に、実装内容、検証コマンド、結果、コミットを追記する。
- UIだけを先行させず、schema/domain/adapter/view/E2Eを必要な範囲で同じスライスに含める。
- 計算へ影響する変更は `approximate` / `unsupported` のfail-closed契約を維持する。

