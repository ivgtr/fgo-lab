# 計算方法と制約

## 対象

宝具ダメージと、その直前に適用する自己効果・準備操作を計算します。複数ターンの行動、敵の全行動、戦闘全体を再現するシミュレーターではありません。

calculatorとrankingは同じscenario・execution・数値計算を使います。ランキングは比較条件と候補を選び、独自のダメージ式を持ちません。

## ダメージと乱数

ATK、宝具倍率、カード補正、クラス・属性相性、攻防補正、宝具威力、特攻、特殊耐性、固定加算・軽減などを、適用条件と順序に従って計算します。float32の丸めを演算境界に適用し、最終整数値を求めます。

ダメージ乱数は900〜1099の200通りです。最低・最大は両端の最終結果、平均は200通りの最終結果の算術平均です。「乱数1000を一度計算した値」と平均が異なることがあります。

数式・32-bit演算の参照元:

- [Atlas Academy: Damage](https://github.com/atlasacademy/fgo-docs/blob/master/deeper/battle/damage.md)
- [Atlas Academy: 32-bit float](https://github.com/atlasacademy/fgo-docs/blob/master/deeper/battle/32-bit-float.md)

## 自己バフと条件効果

利用可能なスキルと、実際に適用した効果を区別します。効果は宝具前の順序付き操作として実行し、後続の条件判定はその時点の状態を参照します。効果や条件の意味は現在のマスターデータから導出します。

「通常のみ」と「成立込み」では条件を満たしたと扱う範囲が異なります。条件の成立、発動確率、確定性は同じ意味ではありません。採用した条件と実行順は詳細で確認してください。敵・味方条件、HP、数量、BP等が必要な場合は、対応する入力・実行状態を使用します。

## 比較と未計算の扱い

rankingは合法な候補を全て評価し、同じダメージでは安定した候補順で選択します。最良候補以外で見つかった、不正・未対応などの計算を妨げる問題も保持します。

入力不足、矛盾した入力、未対応の意味論、指定した比較方針からの除外、確率的な失敗を区別します。計算できない条件を0ダメージや推測値に置き換えません。master更新後は旧masterの候補・詳細・計算結果をそのまま再利用しません。

実装の責務は[アーキテクチャ](architecture.md)、固定ケースとproductionの検証は[テストガイド](testing.md)を参照してください。
