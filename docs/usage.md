# 使い方

## マスターデータ

初回起動時にゲームのマスターデータを取得します。取得・検証に失敗した場合は表示される理由を確認し、通信状態を直して再試行してください。検証済みデータの更新と、保存した所持・育成データは別に管理します。

## ランキング

対象、レベル、宝具Lv、初期OC、クラス相性、自己バフ、条件効果を指定して比較します。「計算基準」では育成の扱いと外部条件を確認できます。

- 「全サーヴァント」は共通の比較条件を使います。
- 「保有サーヴァント」では保有レベル・宝具レベルや保存育成状態を選べます。必要な保存値が不足・不正な場合は、表示されたプロフィールを修正してください。
- 「通常のみ」と「成立込み」は条件効果の扱いが異なります。成立込みの結果を、実際の戦闘で常に出せるダメージとして扱わないでください。
- 詳細では採用した条件・効果・実行順を確認し、その条件を計算機へ引き継げます。

自己バフ、確率的な効果、敵や味方の条件については[計算方法](calculation.md)を参照してください。同じ順位でも、条件や採用した実行順が異なる場合があります。

## 計算機

サーヴァント・宝具、育成値、礼装、対象条件、適用する効果を設定します。結果には最低・平均・最大ダメージと内訳を表示します。入力が不足している場合や実行できない組合せでは、理由に従って条件を修正してください。

ランキングから開いた計算機は、採用条件を引き継ぎます。その後に入力を変更した結果は、元のランキング条件とは別の比較になります。

## 所持・育成

サーヴァントの所持状態と現在値・育成目標を保存できます。育成画面は目標との差分を集計しますが、素材の集計・使用先表示には未完了の範囲があります。必要素材の完全性を保証する表示としては扱わず、ゲーム内でも確認してください。

## 共有とバックアップ

計算結果の共有と、所持・育成データのバックアップは別の機能です。共有用の結果に所持一覧・プロフィールのメモを含めません。バックアップには個人の保存データを含むため、公開するファイルと取り違えないでください。

ユーザーデータはこのブラウザのIndexedDBに保存します。端末やブラウザを変えても自動同期しません。ブラウザの保存領域を消す前にバックアップを保存してください。復元時に形式・版・内容の検証で拒否された場合は、エラーを確認し、元ファイルを保持して対応してください。不正な内容を別の値へ補正して読み込みません。
